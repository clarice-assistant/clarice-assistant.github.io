Clarice – Privacy Policy

Last updated: November 7, 2026

Clarice is a private, single-household assistant. It is not available to the public, and only the owner's own Google account (bradperryassistant@gmail.com) signs in to it.

What data it accesses

With the account holder's permission, Clarice uses Google APIs (Gmail, Google Calendar, Google Drive, Docs, Sheets and related services) to read, organize and send the account holder's own email, calendar events and files.

How data is used

Data is used only to perform tasks the household asks for. It is not sold, not used for advertising, and not shared with third parties except as needed to carry out a requested task (for example, sending an email the user asked to send).

Storage and security

OAuth tokens are stored encrypted on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Clarice's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
